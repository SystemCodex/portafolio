PORTAFOLIO — HEBERT FABIAN PEÑA SANTOS
Versión final V19

ARCHIVO PRINCIPAL
- index.html

ESTRUCTURA
- assets/brand/         Logo HX
- assets/profile/       Fotografía de perfil
- assets/projects/      Imágenes y videos de proyectos
- assets/documents/     Manual y certificados PDF

USO
1. Mantenga index.html y la carpeta assets en el mismo nivel.
2. Para publicar, suba toda esta carpeta al hosting conservando la estructura.
3. El portafolio funciona sin frameworks ni proceso de compilación.
4. Google Fonts es una mejora visual opcional: si no hay conexión, el CSS usa tipografías de sistema como respaldo.

NOTA
Los documentos PDF se visualizan desde el propio portafolio. No cambie las rutas de assets sin actualizar index.html.
